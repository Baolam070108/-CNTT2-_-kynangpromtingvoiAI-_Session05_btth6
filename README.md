- **Prompt 2 – Prompt Chaining:** Dựa vào kết quả bước 1 để lập lịch trình.
- **Prompt 3 – Prompt Chaining:** Lập ngân sách và phân công 10 nhân sự.
- **Prompt 4 – Prompt Chaining:** Xây dựng kế hoạch truyền thông.

- Cần xác nhận hội trường, thiết bị và khách mời trước khi tổ chức.
